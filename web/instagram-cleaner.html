Workflow
No login form on this site. Instagram authentication stays where it belongs: Instagram.
1 · Open InstagramSign in normally in Chrome.
2 · Install helper onceLoad the browser-helper folder as an unpacked Chrome extension.
3 · Connect hereThe website talks to the helper through a same-browser bridge.
4 · Review before actionBatch changes are intentionally limited to selected items.
Security model
The web app never asks for an Instagram password. The helper reads and acts only against the Instagram tab you already opened.
This uses Instagram browser endpoints that are not a stable public API. Instagram can change or reject requests at any time. Do not use this on accounts you do not control.

Why this view is different
Instagram's comment UI changes frequently. The workspace therefore opens the native activity page rather than trying to blindly delete comments through brittle selectors.
You stay in control of the final deletion inside Instagram. The helper does not bypass confirmation dialogs or security checks.
