Browser Tools

One small setup, then you’re ready.

The helper connects the dashboard to the Instagram tab you already have open. You don’t enter your Instagram password on this site.

Download Browser Tools

For Chrome or Brave on a desktop computer.

  1. Download and extract the ZIP file to a folder you can keep.
  2. Open chrome://extensions/ in Chrome or brave://extensions/ in Brave.
  3. Turn on Developer mode.
  4. Choose Load unpacked and select the extracted folder that contains manifest.json.
  5. Open Instagram and sign in there as usual. Leave that tab open.
  6. Return to Social Media Tools and choose Connect Browser Session.
The helper works with the Instagram session in your browser. It doesn’t ask for your password, and scan results are not uploaded by the helper.
Instagram may change how its website works, so some features can stop working until they’re updated. Use the tools only with an account you control.
