# MahiCloud Image Uploads

Upload custom PNG/JPG/WebP images for MahiCloud and its subsites into this directory.

## File naming

Use lowercase English names, hyphens, and a subsite/category prefix so each image can be mapped reliably.

Examples:
- `main-mahiflix.png` — main MahiCloud subsite tile/logo artwork
- `mahiflix-site-nightflix.png` — MahiFlix website card for Nightflix
- `mahiflix-app-filmtv.png` — MahiFlix app card for FilmTV
- `apps-meld.png` — MahiApps listing for Meld
- `linkora-meld.png` — Linkora/WinForge listing for Meld
- `lumr-project-name.png` — Lumr portfolio project artwork

Keep filenames unique and do not put multiple images into one archive. After uploading, send the list of filenames (or tell me “images uploaded”) and I can wire each image into the correct subsite and card.

## Suggested image sizes

- App/service logos: square PNG, ideally 512 × 512, transparent background when possible.
- Project cards or app screenshots: 1200 × 800 or 1600 × 900.
- Hero/banner artwork: 1600 × 900 or larger.

Use readable, sharp images. Avoid adding spaces, Bengali characters, or duplicate filenames.
