# MahiCloud Project Card Icons

Upload square PNG files for the project cards on the MahiCloud homepage here.

Use these exact lowercase filenames:
- `movie-websites.png` — MahiFlix / Movie Websites
- `apps.png` — Apps
- `windows-tools.png` — WinForge / Linkora
- `social-media-tools.png` — Social Media Tools
- `quick-link.png` — Quick Link
- `nextdns.png` — NextDNS Endpoint

Recommended: 512×512 px, square, transparent background where appropriate. Keep filenames exactly as written. Once the PNGs are uploaded, the homepage code can be mapped to them. Uploading files alone does not automatically replace existing icons.
