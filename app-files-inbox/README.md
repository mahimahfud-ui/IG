# App Files Inbox

Upload downloaded app files here so they can be reviewed and organised into the right MahiCloud category later.

## What to upload
- Android packages: `.apk`, `.xapk`, or `.apks`
- TV app packages and related release archives
- A small `.txt` note with the app name, intended category (Movie Apps, Music Apps, or TV Apps), version, and original download/source URL

## Before uploading
- Keep each file below GitHub's 100 MB per-file limit; smaller files are easier to manage.
- Do not upload passwords, API keys, private data, or paid/proprietary app files unless you have permission to redistribute them.
- Files in this public repository can be viewed and downloaded by anyone. This folder is an intake area; uploads here do not automatically add apps to the live website.

When the files are ready, share the filenames in ChatGPT and I can inspect the metadata and prepare the appropriate category entries separately.
